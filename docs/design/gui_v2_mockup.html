②서버 연결 상태 (연결 모드)

필요한 것: EventKind.LINK(상태 전이만 — connected / retrying / standby / quota / rejected) · /status.server를 문자열에서 {url, state}로 확장 · 재등록은 명시적 POST /server/register.

③기억 보기·지우기

나비가 무엇을 기억하는지 사용자가 볼 수 없다. 서비스로 열면 "보고 지울 수 있다"가 신뢰의 바닥이다. 설정에 "기억" 탭을 두고 사실 행을 그대로 보여 준다. 서버 삭제 API(G8 ④)와 짝이다.
